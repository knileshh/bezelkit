Why it fits

        
Most mockup kits put the image in a box with width:100%; height:100% and hope the shapes match. These three things are what bezelkit does differently.

      

      

        

          fit="auto"
          
It reads the shape first

          
Within 4% of the screen, it fills. A little taller, it pins to the top. A full-page capture scrolls. Anything wider is letterboxed with colours sampled from its own edges. Nothing is stretched.

        

        

          402 × 874
          
Real screens, current devices

          
Every frame uses the device's CSS viewport, so a 3× screenshot maps 1:1 and iframes hit real breakpoints. Frames are drawn in CSS, so they stay sharp at any width.

        

        

          chrome="auto"
          
No second status bar

          
Screenshots already have a status bar, so bezelkit only draws one over live HTML and iframes. It's a single custom element with no dependencies, so it works in plain HTML, React, Vue, Svelte, Astro or Markdown.
