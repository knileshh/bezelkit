How it fits

It measures before it frames.

Each <bezel-device> compares your image's shape with the device's real CSS viewport, then picks one of four fits. The notes on the desk are these decisions, read straight from its bezel-fit event. Want a different one? Set fit yourself.

Use it

One script. One tag.

No build step and no dependencies. It is a standard custom element, so any framework just renders the tag. Give it a width and the frame stays sharp at any size.

Plain HTMLReact 19VueSvelteAstroMDXWebflow
<!-- 1. load it once -->
<script type="module"
  src="https://cdn.jsdelivr.net/npm/bezelkit@0/dist/bezelkit.js"></script>

<!-- 2. frame anything -->
<bezel-device device="iphone-17-pro" color="cosmic-orange"
  src="screenshot.png"></bezel-device>

<!-- 3. optional: listen, flip -->
<script type="module">
  const phone = document.querySelector('bezel-device');
  phone.addEventListener('bezel-fit', (e) => console.log(e.detail.fit));
  phone.flip(); // turns it over to show the back
</script>
