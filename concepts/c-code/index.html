Five ways mockups break your screenshots

These come up again and again in issue trackers for mockup kits. Each card starts with the typical result. Turn on bezelkit to render the same content with one attribute changed.

// install

Works wherever HTML does

It's a standard custom element, so frameworks just render a tag. You don't need a wrapper, a provider or a build plugin.

$npm i bezelkit
<script type="module" src="https://cdn.jsdelivr.net/npm/bezelkit@0/dist/bezelkit.js"></script>

One ES module with no runtime dependencies. It also works in Markdown and MDX docs sites, and in Webflow or Framer embeds.

// api

          
A small API

          
Every attribute is also a property (el.safeArea = 'pad'). You also get one event, three exports and some ::part() hooks.

        

      

      

        

          
Attributes <bezel-device>

          
Defaults are shown first. Leave an attribute out and you get the default.

          

            
device
id or alias (iphone, pixel, ipad, macbook…)

            
src
image · video · URL (no src slots your HTML)

            
fit
auto · cover · top · contain · scroll · fill · none

            
color
finish name or any CSS colour

            
orientation
portrait · landscape

            
chrome
auto · on · off (synthetic status bar)

            
safe-area
auto · pad · none

            
side
front · back · both (animated flip)

            
theme · glare · shadow
light · dark · boolean · none

            
url · viewport
browser frames: acme.dev · 1440x900

          

        

        

          
How fit="auto" decides

          
It compares the image's aspect ratio with the screen's, then picks a mode.

          

            
Within 4% of the screen
cover crops a few px

            
Much taller (full-page capture)
scroll inside the screen

            
Slightly taller
top keeps the header

            
Wider
contain letterboxes in edge colours

          

        

        

          
Event bezel-fit

          
Fires once media loads. Use it to catch screenshots taken on the wrong device.

          
el.addEventListener('bezel-fit', (e) => {
  const { fit, mismatch } = e.detail;
  if (Math.abs(mismatch - 1) > 0.04) {
    console.warn(`Screenshot shape is off; using ${fit}`);
  }
});

        

        

          
Exports listDevices · getDevice · defineDevice
